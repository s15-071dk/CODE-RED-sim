# 2026-05-16 作業ログ

## バグ報告（Claude Code → Cursor担当）

### 症状
「Sat危険域！」「インシデント！」などの警告バーが表示されると、画面全体（top-bar・ER俯瞰・右パネル・ログ）が下にズレる。

### 原因
`#game-screen` は `display:flex; flex-direction:column; height:100vh` のフレックスコンテナ。
その中に `#event-banner` と `#alert-bar` が **document flow の要素として**配置されているため、
`display:none` → `display:flex / block` の切り替え時に高さが発生し、下の要素を全部押し下げる。

```
game-screen (flex-column)
  ├─ event-banner  ← show時にheight確保 → 以下が全部ズレる
  ├─ alert-bar     ← show時にheight確保 → 以下が全部ズレる
  ├─ top-bar
  ├─ mobile-tabs
  └─ body-wrap
```

### 修正方針（Cursor担当）

**`#alert-bar`（5秒表示の一時的な警告）**
- `position: fixed; top: 44px; left: 0; right: 0; z-index: 200;` にして flow から外す
- `top: 44px` は `.top-bar` の高さ（`height:44px`）に合わせる
- `.alert-bar.show` は `display:flex` のままでOK

```css
/* 修正後 */
.alert-bar {
  position: fixed;
  top: 44px;
  left: 0;
  right: 0;
  z-index: 200;
  background: #2d0f0f;
  border-bottom: 1px solid #ef4444;
  padding: 3px 14px;
  font-size: 10px;
  color: #fca5a5;
  display: none;
  align-items: center;
  gap: 6px;
}
.alert-bar.show { display: flex; }
```

**`#event-banner`（CT故障中の常時バナー）**
- こちらは `position: fixed; top: 0; left: 0; right: 0; z-index: 201;` にして flow から外す
- 表示中は `.top-bar` などと重なるが、CT故障は緊急告知なのでオーバーレイでOK
- または `.top-bar` の `top: 0` → `top: 36px（bannerの高さ）` にズラす方法でも対応可

**対象ファイル**
- `styles/main.css` の `.event-banner` と `.alert-bar` を修正するだけ（JSは変更不要）

### スマホ対応での注意
スマホ（768px以下）では `.mobile-tabs` の高さも加味して `top` を調整すること。
