## 概要

**CODE RED ER** は、救急外来（Emergency Room）を舞台にしたリアルタイム医療シミュレーションゲームです。

プレイヤーは救急医として、次々と搬送される患者をトリアージし、限られたベッドとスタッフを管理しながら検査・処置を行い、適切な転帰（ICU転送・入院・帰宅）を決定します。医療知識がなくても直感的に楽しめる設計になっています。

---

## ゲームの特徴

- **リアルタイムの患者管理**  
  救急搬送の入電を受け、患者をベッドへ割り当て、バイタルサインの変化を確認しながら対応します。

- **信号灯システムによる検査結果**  
  検査結果を 🔴🟡🟢 の3色でわかりやすく表示。医療知識がなくても「赤が多いほど重症」と直感的に判断できます。

- **スタッフ疲労管理**  
  看護師・研修医にはそれぞれ個性と疲労ゲージがあります。疲弊したスタッフを適切に休憩させないとインシデントが発生します。

- **患者満足度システム**  
  不適切な処置・転帰ミス・入電拒否などで満足度が低下。ゼロになるとゲームオーバーです。

- **段階的なステージ設計**  
  チュートリアルから始まり、患者数・入電頻度・スタッフ管理の複雑さが徐々に上がります。

## ゲームの流れ

```
救急入電 → 受け入れ承諾
    ↓
患者をベッドへドラッグ＆ドロップ
    ↓
検査・処置をオーダー（点滴 / 血液検査 / 心電図 / エコー / X線 / CT）
    ↓
結果が 🔴🟡🟢 で返ってくる
    ↓
転帰を決定（ICU転送 / 一般病棟入院 / 帰宅）
    ↓
スコアが加算 → 次の患者へ
```

| Stage 3 | スタッフ管理（疲労システム有効） | ★★★ |
| Stage 4 | 夜間シフト（スタッフ減員） | ★★★ |
